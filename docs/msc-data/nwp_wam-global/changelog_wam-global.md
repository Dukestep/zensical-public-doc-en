# Chronology of changes to the WAM-Global wave prediction system

## Tuesday September 18, 2018

#### Retirement of the "WAM-Global" wave prediction system from the Canadian Meteorological Centre (CMC) set of production suites
After many years of loyal and essential service, the "WAM-Global" wave prediction system officially retired from the Canadian Meteorological Centre (CMC) on September 18, 2018. Products that were generated by "WAM-Global" are now available from the [Global Deterministic Wave Prediction System (GDWPS)](../nwp_gdwps/readme_gdwps.md).
